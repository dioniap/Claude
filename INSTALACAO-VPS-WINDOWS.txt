================================================================================
  PARTE 7 - DEIXAR O SISTEMA RODANDO SEMPRE (mesmo apos reiniciar a VPS)
================================================================================

: Use o MESMO metodo que seus outros sistemas usam para ficar no ar.
: Se voce nao sabe qual e, o mais simples no Windows e o PM2 (abaixo).

: 1) Instala o PM2 (gerenciador de processos Node):
npm install -g pm2

: 2) Sobe o atende-laudos pelo PM2:
cd C:\Users\dioni.WIN-HP2EQOL52VI\atende-laudos
pm2 start src/server.js --name atende-laudos

: 3) Salva a lista para reiniciar sozinho:
pm2 save

: 4) Comandos uteis do dia a dia:
:     pm2 status                 (ver se esta rodando)
:     pm2 logs atende-laudos     (ver os logs em tempo real)
:     pm2 restart atende-laudos  (reiniciar, ex.: apos editar knowledge\base.md)
:     pm2 stop atende-laudos     (parar)
:
: OBS: para o PM2 iniciar junto com o Windows, o jeito mais robusto e instalar
: como servico. Se seus outros sistemas ja fazem isso de alguma forma
: (NSSM, Agendador de Tarefas, etc.), use o mesmo padrao para o atende-laudos.


================================================================================
  PARTE 8 - PUBLICAR NA INTERNET (Cloudflare Tunnel) - vendalaudos.simplificapn.com
================================================================================

: Seu omnichannel (atendimento.simplificapn.com) ja e publicado pelo Cloudflare.
: Voce so precisa adicionar mais um endereco (vendalaudos) apontando para a
: porta local 3010.

: --- OPCAO A: pelo painel do Cloudflare (mais facil) ---
: 1. Acesse  https://one.dash.cloudflare.com
: 2. Menu:  Networks -> Tunnels -> (clique no seu tunel existente)
: 3. Aba "Public Hostname" -> botao "Add a public hostname":
:        Subdomain:     vendalaudos
:        Domain:        simplificapn.com
:        Service Type:  HTTP
:        URL:           localhost:3010
: 4. Salve. O Cloudflare cria o DNS sozinho. Em ~1 minuto,
:    https://vendalaudos.simplificapn.com ja abre o painel.

: --- OPCAO B: pelo arquivo de config do cloudflared (se voce configura por arquivo) ---
: Abra o config do tunel (geralmente em C:\Users\dioni.WIN-HP2EQOL52VI\.cloudflared\config.yml)
:     notepad %USERPROFILE%\.cloudflared\config.yml
: E adicione uma linha na secao "ingress", ANTES da linha "service: http_status:404":
:
:     - hostname: vendalaudos.simplificapn.com
:       service: http://localhost:3010
:
: Depois reinicie o servico do cloudflared (o mesmo comando/servico que voce ja usa).

:     npm install --global windows-build-tools
:   (ou instale o "Desktop development with C++" pelo Visual Studio Build Tools)

:   tambem a URL do tunel na PARTE 8 (localhost:3011).

: O painel abre em localhost mas nao em vendalaudos.simplificapn.com:
:   O problema esta no tunel do Cloudflare (PARTE 8) - confira se o hostname
:   aponta para a porta certa e se o cloudflared esta rodando.
